# 第X次需求确认：完善首页看板和预警逻辑

## 用户需求

根据实际出版校对工作场景，对系统展示方式进行调整。

核心需求：

1. 首页需要展示当前等待处理书稿；

2. 项目按照优先级排序；

3. 不同流程节点使用不同颜色；

4. 急稿和重要急稿增加星级标识；

5. 滞留项目需要单独进入预警区域；

6. 阈值按照稿件重要程度设置。

---

## 确定设计方案

### 稿件等级

普通稿件：

30天

急稿：

15天

重要急稿：

7天

### 页面展示

采用：

卡片式看板

而非：

传统表格。

原因：

管理人员需要快速识别和处理任务。
